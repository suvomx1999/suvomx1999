### 🏥 MedAI — Federated Clinical Intelligence System
[![MedAI](https://img.shields.io/badge/Research_Paper-In_Review-orange?style=for-the-badge&logo=arxiv&logoColor=white&labelColor=0d1117)](https://github.com/suvomx1999)

### 🌾 Kisan Yield Guard — Production MLOps Pipeline

[![GitHub Actions](https://img.shields.io/badge/CI%2FCD-2088FF?style=for-the-badge&logo=githubactions&logoColor=white&labelColor=0d1117)]()

> End-to-end **MLOps** crop yield prediction pipeline with Evidently AI drift detection, MLflow experiment tracking, automated CI/CD retraining triggers, and FastAPI serving. Built for real-world agricultural deployment.

---

### 💊 De Novo Drug Discovery Pipeline
[![PyTorch](https://img.shields.io/badge/PyTorch-EE4C2C?style=for-the-badge&logo=pytorch&logoColor=white&labelColor=0d1117)]()
[![GNN](https://img.shields.io/badge/Graph_Neural_Networks-58a6ff?style=for-the-badge&logoColor=white&labelColor=0d1117)]()

> Generative molecular design system targeting **SARS-CoV-2 Mpro** using graph diffusion models + active learning. Predicts binding affinity via GNN-based molecular property estimation with ESOL/BACE benchmark validation.

---

### 🤖 A2A MCP Multi-Agent System
[![LangGraph](https://img.shields.io/badge/LangGraph-1C3C3C?style=for-the-badge&logo=langchain&logoColor=white&labelColor=0d1117)]()
[![MCP](https://img.shields.io/badge/MCP_Protocol-58a6ff?style=for-the-badge&logoColor=white&labelColor=0d1117)]()
[![Groq](https://img.shields.io/badge/Groq_LLM-F55036?style=for-the-badge&logoColor=white&labelColor=0d1117)]()

> Domain-agnostic **Agent-to-Agent** coordination framework using Model Context Protocol. Autonomous tool use, dynamic task decomposition, and LangGraph state machine orchestration with Groq/Llama inference.

---

### 🎙️ TamilCLIP — Cross-Modal Contrastive Learning
[![Wav2Vec2](https://img.shields.io/badge/Wav2Vec2-FF6F00?style=for-the-badge&logo=huggingface&logoColor=white&labelColor=0d1117)]()
[![IndicBERT](https://img.shields.io/badge/IndicBERT-58a6ff?style=for-the-badge&logo=huggingface&logoColor=white&labelColor=0d1117)]()

> Cross-modal contrastive learning system aligning **Tamil speech** (Wav2Vec2) with text (IndicBERT) via InfoNCE loss — inspired by CLIP's vision-language alignment. Built for low-resource Indian language understanding.

---
